## 2. 目指す状態

現在形に対する差分で書く。要件は `### 要件 <id_prefix>-R<n>: <1 文>` と、その下の `- <id_prefix>-R<n>.<m> Given … When … Then …`。

変更された要件は、見出しは変更後の文だけを書く（`→` で変更前を並べない。変更前の文は §3 か PR に書く）。受入は、書いた ID の行だけが現在形の同じ ID の行と入れ替わり、現在形に無い ID は足される。書かない ID の受入は現在形に残る。変更・削除は取り込み先の現在形 README の要件 ID（例 `CHAT-R2`。この提案の id_prefix ではない）で書く。受入だけを変えるときも、見出しには現在形の今の文をそのまま書く（空だと exit 1）。
なお `design-merge` が当てるのは、kind が製品の機能で domain が 1 つの提案だけ（ほかは手で現在形に取り込む）。

削除された要件は、要件ごと消すときは `- <現在形の id_prefix>-R3`、受入だけ消すときは ID で `- <現在形の id_prefix>-R2.2` と書く（受入の行だけが消える）。1 行に ID は 1 つ。
