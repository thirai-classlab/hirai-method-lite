# 保留タスク

今は着手しないタスクの置き場。[`list.md`](list.md) から移してくる。

- 保留にしたタスクは list.md から削除し、この表に 1 行として移す
- 再開条件が満たされたら、この表から削除して list.md に 未着手 で戻す
- 不採用にしたタスクも行を消さず、状態を `不採用` にして理由と判断日を残す

| # | 状態 | タスク | 保留理由 | 再開条件 | 元の設計 |
|---|---|---|---|---|---|
| — | 保留 | (例・架空) 通知のメール配信 | 送信基盤の選定が未了 | 送信基盤を決定したとき | [draft/notify-email.md](../draft/notify-email.md) |

## 列の意味

| 列 | 中身 |
|---|---|
| **#** | list.md にいたときの番号。番号を持たずに保留入りしたものは `—` |
| **状態** | 保留 / 再検討 / 不採用 |
| **タスク** | 何をやる予定だったかを 1 行 |
| **保留理由** | なぜ今やらないかを 1 行。「優先度が低い」ではなく、何が足りないかを書く |
| **再開条件** | 何が起きたら list.md に戻すか。不採用の行には判断日と理由を書く |
| **元の設計** | `docs/draft/` の該当ファイルへのリンク。無い場合は `—` |

不採用の記入例:

```
| 7 | 不採用 | 独自エディタの実装 | — | 不採用 2026-08-22: 既存 OSS で代替可能と判明 | [draft/editor.md](../draft/editor.md) |
```
